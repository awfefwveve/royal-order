## 1. 프로젝트 기본 방향

### 1.1 그래픽 스타일

본 프로젝트의 공식 그래픽 스타일은 다음과 같다.

- 장르: Dark Fantasy / High Fantasy
- 그래픽 방향: 극사실주의 시네마틱 리얼리즘
- 목표 품질: AAA급 콘솔 게임 그래픽
- 기준 엔진: Unreal Engine 5
- 렌더링 방식: Physically Based Rendering (PBR)
- 기본 화면 비율: 16:9
- 기준 해상도: 2560 × 1440
- 기본 색상 작업: Linear Workflow / sRGB 출력

### 1.2 핵심 디자인 철학

모든 그래픽은 실제 세계에 존재할 수 있을 정도의 물리적 설득력을 가져야 한다.

단순히 디테일을 많이 넣는 것이 고품질을 의미하지 않는다.

다음 우선순위를 반드시 지킨다.

1. 형태와 구조의 완성도
2. 실루엣의 명확성
3. 재질의 물리적 설득력
4. 빛과 색상의 통일성
5. 디테일의 완성도
6. 시각적 연출

불필요한 장식, 과도한 입자, 무분별한 스크래치, 과도한 발광 효과는 지양한다.

모든 에셋은 동일한 세계관에서 제작된 것처럼 보여야 한다.

# 2. 형태와 구조 (Shape & Form)

### 2.1 인체 비율

| 항목 | 기준 |
|---|---|
| 일반 성인 인체 | 7.5~8등신 |
| 영웅형 캐릭터 | 8등신 전후 |
| 기준 인간 신장 | 180cm |
| 왕 신장 | 185~195cm |
| 기사 신장 | 175~190cm |
| 형태 과장 | 기본 10%, 최대 20% 지향 |

현실적인 인체 해부학을 기반으로 한다.

근육, 관절, 골격, 무게중심이 자연스러워야 하며 과도한 근육 왜곡은 금지한다.

### 2.2 실루엣

캐릭터는 축소된 화면에서도 직업과 전투 역할을 구분할 수 있어야 한다.

- 왕: 수직적이고 권위적인 실루엣
- 중갑 기사: 넓고 무거운 실루엣
- 경갑 기사: 날렵하고 유선형인 실루엣
- 마법 관련 장비: 원형, 방사형, 기하학적 형태
- 몬스터: 비대칭적이고 위협적인 실루엣

### 2.3 형태 언어

왕실 디자인은 대칭성과 수직성을 기본으로 한다.

기사들은 각자의 전투 역할에 따라 형태를 차별화한다.

장비와 갑옷의 장식은 기능적 구조를 해치지 않아야 한다.

### 4.3 표면 표현

- 금속: 실제 반사 특성과 미세한 마모 표현

- 석재: 미세한 표면 불균일성과 풍화
- 피부: 모공, 미세 주름, Subsurface Scattering
- 목재: 나뭇결과 마모 표현

외곽선은 기본적으로 사용하지 않으며 빛과 명암으로 형태를 표현한다.

# 5. 화면 구성과 카메라 (Composition & Camera)

### 5.1 카메라

| 항목 | 기준 |
|---|---|
| 기본 화각 | 40mm |
| 일반 촬영 | 35~50mm |
| 인물 전신 | 50mm |
| 전투 장면 | 35~40mm |
| 인물 근접 | 50~85mm |
| 카메라 높이 | 흉부~눈높이 |

### 5.2 배경

전경, 중경, 원경의 명확한 깊이 구조를 유지한다.

- 전경: 높은 디테일
- 중경: 중간 디테일
- 원경: 절제된 디테일
- 대기 원근을 사용하여 깊이 표현
- 배경은 캐릭터보다 시각적으로 튀지 않도록 관리

### 5.3 로딩 화면

로딩 UI는 별도 제작한다.

원화 제작 시에는 타이틀, 로딩바, 상태 문구를 포함하지 않는다.

게임에 삽입할 배경 원화와 캐릭터만 제작한다.

# 6. 캐릭터 제작 및 3D 전달 규격

모든 주요 캐릭터는 실제 3D 모델링이 가능한 제작용 원화로 제작한다.

### 6.1 필수 턴어라운드

각 캐릭터별로 다음 자료를 제작한다.

1. 정면 (Front View)
2. 측면 (Side View)
3. 후면 (Back View)
4. 3/4 뷰 (Three-Quarter View)
5. 얼굴 및 투구 상세도
6. 갑옷 및 장비 상세도
7. 재질 및 색상 시트

### 6.2 턴어라운드 규격

| 항목 | 기준 |
|---|---|
| 카메라 | Orthographic |
| 정면 | 0도 |
| 측면 | 90도 |
| 후면 | 180도 |
| 자세 | Neutral A-Pose |
| 배경 | 무채색 단색 |
| 해상도 | 뷰별 4096px 목표 |
| 인체 비율 | 모든 뷰에서 동일 |
| 장비 위치 | 모든 뷰에서 일치 |
| 조명 | 형태 확인이 가능한 균일한 조명 |

정면, 측면, 후면은 동일한 캐릭터 모델을 기준으로 제작해야 한다.

각 뷰에서 갑옷의 크기, 문양, 장비, 신체 비율이 달라지는 것을 금지한다.

### 6.3 모델링 기준

- Unreal Engine 5 기준
- 1 Unreal Unit = 1cm
- 현실적인 실제 치수 적용
- High Poly Sculpt
- Retopology
- UV Unwrapping
- PBR Texture
- Normal / Roughness / Metallic / Base Color
- 필요에 따라 AO 및 기타 보조 맵 사용

캐릭터는 장비별 분리 및 교체가 가능한 구조를 고려한다.

# 8. 시각 효과 (VFX)

왕의 능력은 소환과 아군 강화로 구분한다.

### 8.1 소환 마법

- 기본 색상: 황금색
- 형태: 원형 및 방사형
- 연출: 중심부 에너지 응축
- 진행: 룬 회전 및 입자 확산
- 완료: 빛의 붕괴와 실체화
- 전체 연출 시간: 2~5초

### 8.2 버프 마법

- 기본 색상: 황금색
- 형태: 캐릭터를 감싸는 수직형 오라
- 연출: 얇은 발광과 입자
- 강화 단계: 문양 및 입자 밀도 증가

### 8.3 공통 규칙

마법은 화려하되 캐릭터의 형태와 실루엣을 가리면 안 된다.

입자를 무분별하게 많이 사용하지 않는다.

# 11. 전체 게임 에셋 통일성

모든 에셋은 다음 규칙을 공유한다.

1. 캐릭터와 무기의 실제 크기 관계 유지
2. 캐릭터와 배경의 렌더링 스타일 통일
3. 플레이어와 몬스터의 실루엣 구분
4. 아이템 등급별 디자인 체계 유지
5. 진영별 색상과 문장 체계 유지
6. UI와 인게임 그래픽의 디자인 통일
7. 애니메이션 프레임 간 형태 유지
8. 동일한 PBR 재질 철학 적용
9. 동일한 색상 및 라이팅 철학 적용
10. 모든 에셋의 시각적 완성도 통일

### 아이템 등급

일반 → 고급 → 희귀 → 영웅 → 전설

등급이 높아질수록 단순히 발광 효과만 증가시키는 것이 아니라 형태, 재질, 장식, 문양 자체에 차별성을 부여한다.

# 13. 최상위 아트 디렉션 원칙

본 프로젝트의 모든 시각적 결과물은 다음 원칙을 최우선으로 한다.

**극사실주의는 디테일의 양이 아니라 형태, 재질, 빛, 구조의 설득력으로 완성한다.**

- 불필요한 디테일을 추가하지 않는다.
- 모든 부분을 화려하게 만들지 않는다.
- 실루엣과 형태를 먼저 완성한다.
- 재질별 물리적 특성을 구분한다.
- 캐릭터의 시각적 우선순위를 유지한다.
- 모든 에셋의 세계관과 디자인 언어를 통일한다.
- 원화와 3D 모델링 결과물 사이의 형태적 일관성을 유지한다.

**최종 목표: 하나의 통일된 세계관 안에서 제작된 AAA급 극사실주의 다크 판타지 게임 그래픽.**
