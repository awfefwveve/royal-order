# ROYAL ORDER 에셋 규격 (사운드 · 3D · UI)

이 규격대로 만들어 주면 `SkinSet` 칸에 넣기만 하면 게임에 바로 들어간다 (판정은 그대로, 겉모습만 바뀜).
파일은 `Assets/KnifeWar/Art/` 아래에 넣고 이름은 아래 표의 **파일 이름** 그대로.

## 공통 규칙

| 항목 | 규칙 |
|---|---|
| 3D 파일 | **FBX** (애니메이션 포함은 FBX 하나에 여러 클립 또는 클립별 FBX) |
| 단위 · 방향 | 1 = 1m, **발이 원점(0,0,0)**, 앞이 **+Z**, 위가 **+Y** |
| 텍스처 | PNG, PBR 메탈릭 세트: `_Albedo`(색) · `_Normal` · `_MetallicSmoothness`(R=금속, A=매끈함) · 필요하면 `_Emission` |
| 팀 색 | 같은 모델에 **파랑 팀 / 빨강 팀** 텍스처 두 벌 (또는 팀 색 마스크 한 장 `_TeamMask`, 흰색 부분이 팀 색) |
| 스타일 | 키아트 톤: 어두운 고딕 판타지, 금색·붉은 망토, 차가운 하늘 |
| 사운드 | **WAV 48kHz 16bit**, 효과음은 **모노**, 음악·분위기는 스테레오. 앞뒤 무음 잘라서. 효과음 최고점 -1dBFS, 음악 -14 LUFS |
| 변형 | 자주 나는 소리는 **3개씩**(`_01`~`_03`) — 게임이 번갈아 틀어 반복감을 줄임 |

## 1. 캐릭터 (3D)

| 파일 이름 | 내용 | 폴리곤 | 텍스처 |
|---|---|---|---|
| `knight_blue.fbx` / `knight_red.fbx` | 황실 기사 (팀별 갑옷 색) | 15k~25k 삼각형 | 2048 |
| `king_blue.fbx` / `king_red.fbx` | 왕 (왕관·망토, 무기 없음 또는 홀) | 15k~25k | 2048 |

- 키 **1.8m** (게임이 판정 키에 자동으로 맞추지만, 비율은 사람 체형으로)
- **유니티 휴머노이드 리그** (일반 사람 뼈대: 엉덩이·척추·목·머리·팔·손·다리·발). 오른손 뼈에 칼이 붙는다
- 망토·머리카락은 뼈 추가 OK (흔들림은 게임에서 처리)

### 캐릭터 애니메이션 (휴머노이드라 기사·왕 공용, 각 클립 루프 여부 표시)

| 클립 | 길이 | 루프 |
|---|---|---|
| `idle` 서기 | 2~4초 | O |
| `walk` 걷기 (약 2.5m/s) | 1초 | O |
| `run` 달리기 (약 5m/s) | 0.7초 | O |
| `crouch_idle` / `crouch_walk` 앉기 | 각 1~2초 | O |
| `jump_start` / `jump_air` / `jump_land` | 0.2 / 루프 / 0.3초 | 중간만 O |
| `slash` 베기 (오른손 칼, 왼→오) | **0.45초** (칼이 닿는 순간 0.06초) | X |
| `stab` 찌르기 (앞으로) | **1.0초** (닿는 순간 0.22초) | X |
| `hit_react` 맞음 (상체만) | 0.3초 | X |
| `death` 쓰러짐 | 1~1.5초 | X (마지막 자세 유지) |
| `summon` 왕 소환 (팔 들어 올림) | 0.8초 | X |
| `buff` 왕 버프 (지팡이·손 들기) | 0.8초 | X |

> 베기·찌르기 길이와 '닿는 순간'은 판정 시간과 같아야 함 (지금 값: 베기 0.45초·닿음 0.06초, 찌르기 1.0초·닿음 0.22초). 다르게 만들면 알려줘, 판정 쪽을 맞춘다.

## 2. 칼

| 파일 이름 | 내용 | 폴리곤 | 텍스처 |
|---|---|---|---|
| `knife_view.fbx` | **1인칭 화면용**: 오른손(장갑) + 칼. 손 포함 권장 | 5k~10k | 2048 |
| `knife_view_anims` | 1인칭 클립: `idle`(숨쉬기, 루프), `slash` 0.45초, `stab` 1.0초, `run`(흔들림, 루프), `equip` 0.4초 | | |
| `knife_hand.fbx` | 3인칭 손에 들리는 칼 (칼만) | 1k 이하 | 512 |

- 칼 길이 약 30~40cm, 손잡이 끝이 원점, 칼날이 **+Z**
- 1인칭 모델 원점 = 카메라(눈) 위치. 화면 오른쪽 아래에 보이게 배치해서 보내 줘도 됨

## 3. 몬스터 (왕이 소환)

수백 마리를 한 번에 그리므로 **뼈 없는 고정 메시**. 걷는 느낌은 게임이 흔들어서 낸다 (나중에 VAT로 교체 가능).

| 파일 이름 | 종류 | 크기(높이) | 폴리곤 | 텍스처 |
|---|---|---|---|---|
| `monster_0_grunt.fbx` | 졸병 (빠르고 약함, 근접) | 약 1.2m, 폭 0.8m | 1k~2k | 512 |
| `monster_1_tank.fbx` | 탱커 (느리고 단단, 근접) | 약 1.8m, 폭 1.2m | 2k~3k | 512 |
| `monster_2_ranged.fbx` | 원거리 (약함, 2.5m 밖에서 공격) | 약 1.1m, 폭 0.6m | 1k~2k | 512 |

- 텍스처는 **팀별 두 벌** (`_blue`, `_red`) 또는 `_TeamMask`
- 자세는 **걷는 중간 자세** 한 장면으로 고정

## 4. 맵

맵 구조(길 모양·폭)가 확정되면 길이 수치를 여기에 채운다. 지금 만들어도 되는 건 **조각(모듈)** 단위:

| 파일 이름 | 내용 | 규격 |
|---|---|---|
| `bridge_straight.fbx` | 길 바닥 조각 | 길이 **4m** 단위, 폭은 중앙길 기준 (확정 후), 윗면 높이 0 |
| `bridge_curve_90.fbx` | 굽은 길 조각 | 위와 같은 폭 |
| `bridge_rail.fbx` | 난간·가장자리 장식 | 4m 단위, 사람 허리 높이 이하(밖이 보여야 함) |
| `base_blue.fbx` / `base_red.fbx` | 양쪽 진영 (왕이 서는 곳) | 약 12×12m 바닥 + 성문·깃발 |
| `env_backdrop.fbx` | 멀리 보이는 성·절벽·하늘섬 (키아트 분위기) | 판정 없음, 폴리곤 자유(LOD 2단계) |
| `skybox_*.png` | 하늘 6면 또는 HDR 1장 | 2048 |

- 충돌은 게임이 따로 가지고 있음 → 겉모습 모델은 모양만
- 길 위에 서 있는 물체(기둥 등)는 판정과 어긋나므로 **길 바깥에만**

## 넣는 순서 (받으면 Claude가 함)
1. 파일을 `Assets/KnifeWar/Art/` 에 넣기
2. 유니티 메뉴 `KnifeWar/외형/스킨 설정 파일 열기` → 칸에 연결
3. 판정 키·칼 위치·애니메이션 길이 확인 후 맞춤
