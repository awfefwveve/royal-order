# ROYAL ORDER (KnifeWar)

외나무다리 위 6대6 칼 대전. 기사 5명은 칼로만 싸우고, 팀마다 왕 1명이 몬스터를 소환해 적진을 압박합니다.
스팀 없이 자체 계정·자체 런처로 북미·유럽·아시아 동시 출시를 목표로, **넷코드·백엔드·배포를 외부 게임 솔루션(Photon·Nakama 등) 없이 직접** 만들었습니다.

- 단계: 프로토타입 완료 → 버티컬 슬라이스 진행 중 (그래픽은 아직 캡슐 모형)
- 만든 사람: 김보정 (ASTREL) · 구현은 Claude와 페어로 진행, 구조와 결정은 직접
- 포트폴리오: https://astrelgames.com/team/bojung

## 핵심 설계

1. **판정은 서버가 최종.** 클라이언트는 입력만 보내고 내 캐릭터를 먼저 움직여(예측) 화면을 빠르게 보여줍니다. 서버 결과와 다르면 살짝 보정합니다. 남의 캐릭터는 받은 위치 사이를 이어 그립니다(보간).
2. **핑이 달라도 공정한 칼 판정.** 서버가 공격자가 본 순간으로 상대 위치를 되감아(최대 250ms) 맞았는지 봅니다. 입력은 몇 틱씩 겹쳐 보내 패킷 하나가 빠져도 동작합니다. 핑 118ms·3명 접속 시험에서 판정 정상, 예측 오차 최대 8mm.
3. **몬스터는 바뀐 것만 보낸다.** 몬스터 위치는 같은 규칙으로 클라도 계산할 수 있으니, 생성·피격·사망 같은 사건만 보냅니다. 처음 들어오거나 재접속하면 전체 상태를 한 번 보냅니다.
4. **틱이 바뀌어도 체감은 같다.** 판정 수치를 전부 ms로 정의해서 64틱·128틱 어느 쪽이든 같은 거리·같은 속도로 동작합니다. 클라는 접속한 서버의 틱을 자동으로 따릅니다.
5. **껍데기와 판정 분리.** `SkinSet` 파일 하나에 캐릭터·칼·몬스터·소리를 넣으면 겉모습만 바뀌고 판정은 그대로입니다. 데디 서버는 외형을 아예 불러오지 않습니다.

## 백엔드 (`Backend/src`)

- 자체 계정: 이메일 가입·인증, 이름#태그, 비밀번호 PBKDF2-SHA256(21만 회), 10회 실패 시 15분 잠금, 비밀번호 변경 시 다른 기기 로그아웃, 약관 버전이 바뀌면 재동의해야 매칭
- 매칭: 리전별 핑으로 지역 고르기, MMR 범위를 기다릴수록 넓힘, 빈자리는 봇, 파티(최대 6명) 같은 팀 보장
- 랭크: Elo MMR, 티어 7단계, 배치 5판, 리더보드
- 운영: 신고 목록·기간/영구 제재, 점검 모드·공지, 클라 오류 보고 조회, IP당 요청 제한
- 게임 서버 관리: 등록·하트비트·배정, 아무도 안 들어온 경기 90초·전원 이탈 120초·1시간 초과 시 무효 처리 후 반납
- 저장소: PostgreSQL (`-p:UsePostgres=true`), 개발용은 파일

```sh

cd Backend/src && dotnet run

```
