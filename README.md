## 장부는 하나: 이 저장소

일한 흔적이 곧 보고예요. 사내 작업장(work.astrelgames.com) 로비 총괄판이 이 저장소를 자동으로 읽어요.

| 파트 | 여기서 하는 일 | 사이트에 자동으로 보이는 것 |
| --- | --- | --- |
| 프로듀싱 | Milestones (목표·범위·완료 기준·마감), `STAGE.md` 첫 줄 | 공정 위치, 마일스톤 진행률, 막힌 곳 |
| 디렉팅 | `design/vision.md` | 한 줄 비전, 핵심 재미 |
| 기획 | `design/M번호-이름.md`, `기획` 이슈 | 기획서, 남은 기획 일 |
| 프로그래밍 | `프로그래밍` 이슈, 커밋에 `#번호` | 남은 일, 커밋, 버그 |
| 아트 | `아트` 이슈, `Assets/Art/<분류>/` | 남은 일, 들어온 에셋 |

## 일하는 순서

회사 공통 공정은 [PLAYBOOK.md](PLAYBOOK.md). 이 게임의 현재 위치는 [STAGE.md](STAGE.md) 맨 윗줄.
